# Ordinul MDLPA nr. 833/2024

Actul este importat metadata-only. Lista standardelor armonizate este anexă a ordinului; standardele individuale și lista integrală nu sunt reproduse și nu devin noduri separate.

Art. 3 abrogă Ordinul MDLPA nr. 313/2023. Actul abrogat este documentat ca referință externă absentă, fără relație de graf deoarece schema actuală nu modelează `repeals`.
