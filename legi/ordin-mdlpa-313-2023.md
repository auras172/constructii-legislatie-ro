# Ordinul MDLPA nr. 313/2023

Import metadata-only pentru ordinul care aprobă lista cu indicativele standardelor române care transpun standarde europene armonizate din domeniul produselor pentru construcții.

## Modelare

Ordinul are 3 articole și 1 anexă. Lista standardelor este parte integrantă din ordin și nu este modelată ca nod separat. Standardele individuale și textul integral al anexei nu sunt importate.

## Statut și relații

Art. 3 abrogă Ordinul nr. 1.687/2019. Ulterior, Ordinul MDLPA nr. 833/2024 abrogă explicit Ordinul nr. 313/2023 la data publicării sale. Statutul este `repealed` pe baza acestei acțiuni oficiale ulterioare.

Nu este adăugată relația de abrogare către Ordinul 833/2024: schema curentă nu suportă `repeals` sau `repealed_by`, iar succesiunea nu este remapată ca `amends`, `references` sau `related_to`. Ordinul 833/2024 există local și este documentat ca dovada acțiunii, fără relație structurată pentru abrogare. Sunt adăugate doar `references -> hg-1236-2012` și `references -> hg-477-2020`, pe baza citărilor explicite din preambul.

## Temporalitate și surse

Portalul confirmă publicarea în M.Of. nr. 207/13.03.2023. Nu este setată `effective_date`: textul nu oferă o dată calendaristică sau o regulă distinctă de intrare în vigoare pentru acest ordin, iar abrogarea ulterioară nu este modelată ca interval temporal.
